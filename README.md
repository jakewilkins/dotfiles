# ~/

## To install

First off, don't. These are mine, hands off.

```sh
git clone --recursive https://github.com/jakewilkins/dotfiles.git ~/src/$(whoami)/dotfiles
```

```sh
cd ~/src/$(whoami)/dotfiles
```

```sh
./script/setup
```

Meant for MacOS, with partial Linux support.
